# Student Management API

I developed this Student Management API using C# and ASP.NET Core Web API (.NET 10).

The project helps manage student details such as name, email, phone number, age, course, and address.

### What I Have Done
- Created APIs to add, view, update, and delete student details.
- Connected the project to SQL Server LocalDB.
- Used Entity Framework Core for database operations.
- Created models and DTOs for student data.
- Added validation for student details.
- Used Swagger to test all API endpoints.

### Technologies Used
- C#
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- SQL Server LocalDB
- Swagger
